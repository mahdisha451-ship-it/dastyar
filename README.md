# دستیار — کنترل گوشی با صدا و متن فارسی

دو بخش:
- `android-app/` اپ اندروید (Kotlin + Compose) با حالت صوتی و حالت متنی
- `server/` سرور کوچک (Node.js) که کلید API را نگه می‌دارد و دستورهای پیچیده را به Claude می‌فرستد

## مراحل

### ۱) بارگذاری در GitHub
یک ریپوی جدید بسازید و کل این پوشه را در آن push کنید.
بعد از push، از تب **Actions ← Build APK ← آخرین اجرا ← Artifacts** فایل `dastyar-debug-apk` را دانلود کنید (داخلش `app-debug.apk` است).
اگر بیلد خطا داد، لاگ را برای من بفرستید تا درست کنم.

### ۲) دیپلوی سرور روی Render
1. در Render: New ← Blueprint (یا Web Service) و ریپو را وصل کنید. فایل `render.yaml` تنظیمات را می‌گذارد.
2. متغیر `ANTHROPIC_API_KEY` را وارد کنید (کلید از console.anthropic.com).
3. `APP_TOKEN` خودکار ساخته می‌شود؛ مقدارش را از بخش Environment بردارید.
4. بعد از دیپلوی، آدرس `https://نام-شما.onrender.com/health` باید `ok` نشان دهد.
(پلن رایگان Render بعد از چند دقیقه بی‌کاری می‌خوابد و اولین درخواست حدود ۳۰ ثانیه طول می‌کشد.)

### ۳) نصب روی گوشی
1. APK را نصب کنید (اجازه نصب از منبع ناشناس).
2. اپ را باز کنید ← «تنظیمات سرور» ← آدرس سرور و `APP_TOKEN` را وارد و ذخیره کنید.
3. صفحه اصلی ← «فعال‌سازی» Accessibility ← دستیار را روشن کنید.
   (اندروید ۱۳+: تنظیمات ← برنامه‌ها ← دستیار ← سه‌نقطه ← Allow restricted settings، بعد دوباره تلاش کنید.)
4. اجازه میکروفون را بدهید.

## نحوه کار
- دستورهای ساده (فلاشر، باز کردن برنامه، جستجوی گوگل، باز کردن سایت، صدا، برگشت...) مستقیم و بدون اینترنت اجرا می‌شوند.
- بقیه دستورها به سرور می‌روند و اپ مرحله‌به‌مرحله صفحه را می‌خواند و کار می‌کند.
- کپچا/کد امنیتی: اپ می‌ایستد، می‌لرزد و بوق می‌زند. خودتان وارد کنید، بعد بگویید «ادامه بده» یا دکمه شناور «ادامه» را بزنید.
- قبل از پرداخت/حذف/ارسال، تأیید می‌گیرد (قابل خاموش‌کردن در تنظیمات).
- «توقف» با صدا یا دکمه شناور، فوراً همه‌چیز را متوقف می‌کند.

## نمونه دستورها
- «فلاشر را روشن کن» / «فلاشر را خاموش کن»
- «اینستاگرام را باز کن»
- «در گوگل قیمت دلار را سرچ کن»
- «برو سایت digikala.com»
- «برو سایت X، ماشین پراید بار را انتخاب کن، استان و شهر و نمایندگی را انتخاب کن، برو به پرداخت»

## محدودیت‌ها
- روشن/خاموش‌کردن مستقیم وای‌فای و بلوتوث در اندروید ۱۰+ ممکن نیست؛ پنل مربوطه باز می‌شود.
- برنامه‌های بانکی و برخی برنامه‌ها کنترل خودکار را مسدود می‌کنند.
- تشخیص گفتار فارسی گوگل به اینترنت نیاز دارد و وقتی اپ دیگری روی صفحه است ممکن است اندروید میکروفون را محدود کند؛ در این حالت دکمه شناور «ادامه/توقف» همیشه کار می‌کند.
- زمان واکنش واقعی: دستورهای محلی کمتر از یک ثانیه، دستورهای هوشمند چند ثانیه.
